# EHUB-Smart-Electronics-Comparison
EHUB is a full-stack web application that enables users to compare electronic products intelligently using secure authentication and personalized features.
# ⚡ EHUB – Smart Electronics Comparison Platform


---

## 🚀 Features

✅ User Authentication (Signup/Login)  
✅ JWT-Based Secure Authorization  
✅ Protected Routes (Unauthorized users restricted)  
✅ User Profile Management  
✅ Product Comparison System  
✅ Responsive User Interface  
✅ Frontend–Backend Integration  
✅ Secure API Communication

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/yash22-17/EHUB-Smart-Electronics-Comparison.git
```

Move to project directory:

```bash
cd EHUB-Smart-Electronics-Comparison
```

---

### Backend Setup

Install dependencies:

```bash
cd Backend
npm install
```

Start backend server:

```bash
npm start
```

or

```bash
nodemon server.js
```

---

### Frontend Setup

Move to frontend:

```bash
cd Frontend
```

Run project using Live Server or open:

```plaintext
index.html
```

---

## 🔐 Environment Variables

Create `.env` file inside Backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
